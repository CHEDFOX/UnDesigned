# Creative brief: Code is the international language

> **Rendered by the guide.** `npm run design -- xooteq code-language --png`. This campaign uses Humanist Minimal (`campaign.json`); XOOTEQ's own style stays Commercial Modernism.

- **One message (W1):** Code is the language every builder shares, wherever they are.
- **Big idea (O2):** A globe that is also a speech bubble: the world is speaking, and what it says is code. Humanist Minimal's metaphor recipe joins two everyday symbols (a globe, a speech bubble) into one idea.
- **Style:** Humanist Minimal. Ink line over white cut paper, the paper slightly off register, one accent object, at least 40% empty ground, sentence case, three sizes.
- **Colour:** Wada 268 (on the style's recommended list). Pale Nile-blue ground (open sky, the world), deep slate-olive text at 9.97:1, raw sienna as the one accent: the cursor on the equator, where the next line will be typed.
- **Type:** the product's pairing (headline, body, small); the code runs in the pairing's mono face.
- **Motion:** the words arrive one at a time on the style's spring, the headline held for its reading time (media.json). Then the code rows turn like the globe rotating (rows alternate direction), a 3 s move and a 1 s hold per loop, the only thing moving (motion.json: one mover; loops 2–4 s ending still). Reduced motion shows the still poster. No flashes.
- **Copy check:** 0 errors, 0 warnings.
- **Research used:** curvature and handmade marks (visual-preference.json), one focal point (layout.json pop-out), the customer as hero (S1), brand beside the headline (O4).
- **Files:** `poster.copy.json`, art in `products/xooteq/art.mjs` (`code-globe`), output `designs/poster-code-language.svg` (animated) and `.png`.
