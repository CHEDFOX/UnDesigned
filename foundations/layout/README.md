# Layout and grid

Planned. Grids, margins, spacing scale and safe areas for each format (A-series posters, Instagram, stories, web banners).

Rules already set by the messaging playbook (foundations/messaging):

- One idea, one image, few words on posters and outdoor (W6)
- Brand name or logo beside the headline (O4)
- Long copy dark on light, never in all capitals (O8)
- Captions under images in long-form layouts (O9)
- Image and headline add to each other rather than repeat (W5)
