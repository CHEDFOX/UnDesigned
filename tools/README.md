# Tools

Source for the helper pages built into `dist/`.

| Tool | Built to | What it does |
|---|---|---|
| `brand-hub/` | `dist/hub/index.html` (all products, with a switcher) and `dist/<product>/brand-hub/index.html` (one product, to share) | The whole guide in one page: overview, approach (live illustrations), colour (palette library and shortlist), typography (pairings in the product's palette), messaging playbook, live copy checker with preview, and the product's brand message. Rebuilt on every `npm run build`. |
